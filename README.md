# 球为什么会拐弯？

## 基于 AI 视觉识别与力学建模的旋转球飞行轨迹交互系统

本工程面向第六届江苏省力学创新创意竞赛“AI+力学”应用案例赛。作品把旋转球的飞行现象做成一个可操作的网页实验：观众调节初速度、发射角、旋转速度、横风、空气密度、阵风和旋转衰减，观察重力、空气阻力与马格努斯力如何共同改变轨迹；也可以上传轨迹 CSV，让浏览器内置的轻量 AI 近邻回归器反推阻力系数与旋转状态。

## 作品定位

- **力学问题：** 为什么同样的球带有旋转后会出现不同飞行轨迹？
- **力学原理：** 重力、浮力、相对风速、空气阻力、马格努斯力、Reynolds 数、旋转参数、旋转衰减和数值积分。
- **AI 作用：** 从轨迹特征中反推阻力系数和旋转状态，并用反演参数重放轨迹；当前复杂工况会同步进入样本库和回放模型。
- **验证方式：** 无阻力极限解析解、RK4 步长敏感性、复杂工况切换、浮力量级检查和公开轨迹二次验证。
- **提交形态：** 单页网页、案例报告、示范数据和可编辑图件，均可离线运行或复现。

## 快速运行

在项目根目录执行：

```powershell
npx --yes serve .
```

或：

```powershell
python -m http.server 8000
```

然后打开终端显示的本地地址，并进入 `/code/`。进入页面后依次演示“静风基线 → 横风扰动 → 旋转衰减 → 载入公开轨迹 → AI 反演 → 验证”。

## 数据边界

`data/demo_observation.csv` 是用于演示网页流程的示范数据，不应在最终提交时冒充真实实验数据。正式参赛前建议使用手机慢动作拍摄旋转球，提取球心坐标，补充拍摄条件、像素—米标定和重复实验误差。

`data/public_tt3d_sample.csv` 来自公开 TT3D 仓库的 `data/evaluation/3D_gt/001.csv` 样例，保留原始时间、X 坐标和 Z 高度，映射为网页所需的二维 `time_s,x_m,y_m`。它是公开数据复现入口，不是本团队自行测量；原始仓库的当前许可状态和竞赛提交要求应在正式发布前再次核查。

工程不依赖第三方前端框架和在线 API，适合现场展示；AI 模块采用可解释的浏览器端轻量模型，便于评委复核。
